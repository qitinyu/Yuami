# Astro 框架入门

## 什么是 Astro

从零开始学习 Astro 框架，了解静态站点生成的魅力。

## 核心概念

### 岛屿架构

Astro 的岛屿架构允许你在同一个页面中使用多种 UI 框架，而默认情况下所有组件都是静态的，只有标记为"岛屿"的部分才会被 hydrated。

### 性能优势

这意味着更少的 JavaScript 被发送到客户端，更快的页面加载速度。
