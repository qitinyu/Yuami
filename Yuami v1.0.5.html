功能概览

Yuami 是一款基于 Astro 的动漫风格个人博客系统，采用毛玻璃拟态设计语言，支持主题色动态切换、暗黑模式、樱花飘落特效、Live2D 看板娘、音乐播放器、Twikoo 评论系统、文章加密等丰富功能。部署于 Cloudflare Pages，零 JS 框架运行时开销。

快速开始

环境要求

  • Node.js >= 18.0
  • pnpm >= 8.0

安装与运行

# 解压项目
unzip yuami-fin1.zip -d yuami-blog
cd yuami-blog

# 安装依赖
pnpm install

# 本地开发
pnpm dev

# 构建生产
pnpm build

# 部署到 Cloudflare Pages
pnpm deploy
⚠️
重要：public/ 目录下的图片资源因体积限制未包含在代码包中，需自行上传。封面图路径规则：Astro 的 public/ 目录映射到站点根路径，即 public/anime/xxx.webp 的访问路径为 /anime/xxx.webp。

配置说明

所有配置集中在项目根目录的 config.ts 文件中，修改后重新构建即可生效。

内容编辑规范

博客文章 (pots)

存放位置：src/content/pots/{分类}/

分类子目录：Blog/、Github/、Gonju/、Jiqiao/、Les/、Openlist/、Qushi/（可自定义新增）

Frontmatter 模板

---
title: 文章标题
published: "2026-05-24"          # 发布日期（必填）
description: 文章简介             # 可选
tags: [标签1, 标签2]             # 可选
author: 作者名                   # 可选
image: /cover-image.webp         # 可选，文章封面图
licenseName: CC BY-NC-SA 4.0    # 可选，版权协议
encrypted: false                 # 可选，是否加密
password: "123456"              # 加密时必填
---

文章正文，支持 Markdown 和 MDX 语法。
⚠️
注意事项：
  • published 字段为必填，格式建议 YYYY-MM-DD
  • 封面图 image 路径为相对于 public/ 的路径
  • 文件名不能包含空格（Cloudflare 要求），用连字符 - 替代
  • 新增分类只需在 src/content/pots/ 下创建新子目录

CSS 变量体系

全局样式通过 CSS 变量驱动，在 src/styles/global.css 的 :root 和 [data-theme="dark"] 中定义。切换主题色时，所有衍生变量自动重算。

常见问题

Q: 封面图/头像不显示？

A: 确保图片文件已放入 public/ 对应目录。Astro 的 public/ 映射到站点根路径，即 public/anime/xxx.webp → 访问 /anime/xxx.webp。

Q: 文件名有空格导致构建失败？

A: Cloudflare Pages 的 manifest 不支持 URI 编码的文件名。所有文件名禁止包含空格，请用连字符 - 替代。

Q: 朋友圈没有显示文章？

A: 检查 src/data/friends.ts 中友链是否填写了 rss 字段。朋友圈数据在构建时获取，添加后需重新构建部署。

Q: 评论区显示"待配置"？

A: 在 config.ts 中填写 twikoo.envId，该值来自 Twikoo 云函数部署后的环境 ID。

Q: 主题色切换后下次访问闪烁？

A: 主题色通过 <head> 同步脚本从 localStorage 恢复，理论上不会闪烁。若仍有闪烁，检查浏览器是否禁用了 localStorage。

Q: Live2D 模型加载失败？

A: 确认模型文件在 public/live2/models/{模型名}/ 目录下，且 config.ts 中 modelList 的 path 路径正确指向 .model3.json。

Q: 自定义字体不生效？

A: 确认字体文件在 public/font/ 目录，且 config.ts 中 font.fontFile 路径正确。浏览器需支持 .woff2 格式。
